# TalkBridge frontend

React, TypeScript, Vite, Tailwind/DaisyUI and Zustand. The original interface is preserved.

Run `npm ci` then `npm run dev`. The backend must be running on port 5000.

Run `npm run lint` and `npm run build` to check production output.

See the main `../README.md` for environment setup, deployment, moderation and mobile installation instructions. The service worker is registered only in production builds.
